# REQ-001 — Inicio de sesión (ejemplo de referencia)

| Campo | Valor |
|---|---|
| Fecha de registro | 2026-10-05 |
| Fuente | chat |
| URL del SUT | https://www.saucedemo.com |
| Estado | Ejecutado |

## Texto original
> Como usuario registrado quiero iniciar sesión con mi usuario y contraseña para acceder al catálogo
> de productos. Si las credenciales son incorrectas, faltan datos o el usuario está bloqueado, el
> sistema debe mostrar un mensaje de error.

## Criterios de aceptación
- CA-01: Con credenciales válidas se muestra el catálogo "Products".
- CA-02: Con contraseña incorrecta se muestra un error de credenciales.
- CA-03: Si falta el usuario o la contraseña se indica el campo requerido.
- CA-04: Un usuario bloqueado no puede ingresar y se le informa.

## Supuestos adoptados
- Los usuarios de prueba son los publicados en la propia página de saucedemo.
